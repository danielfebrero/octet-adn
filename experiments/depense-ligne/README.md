# Dépense

Quand l'archipel est plein (32 îles), un carré de quatre recettes
différentes n'irrigue plus. À chaque relevé, chaque île retire une
brique de ce carré. La ferme des cases restantes continue. Des trous
s'ouvrent, la nourriture de la technologie s'arrête, des morts peuvent
revenir, et avec elles les naissances où la mutation du stress se pose.

`--depense 0` ne retire rien et n'ajoute aucun tirage. Le drapeau est
hors de Params. L'écriture est `OADNTER9` dès qu'une loi nouvelle est
allumée. Le binaire est `experiments/terrarium_depense`. Parent :
vie-attention.
